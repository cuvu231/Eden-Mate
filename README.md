Eden Mate는 Eden Chat에서 자주 쓰는 접두사를 빠르게 입력하고, 답변 완료 알림과 대화별 통계를 편하게 확인할 수 있도록 돕습니다. 설정과 기록은 브라우저에 저장되며 확장 프로그램 서버로 전송되지 않습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 응답 완료 알림 | 데스크톱 알림과 두 가지 알림음, 음량 미리 듣기, 반복 알림을 지원합니다. |
| 접두사 프리셋 | 여러 문구를 저장하고 단축키 또는 채팅창 옆 목록에서 선택해 입력합니다. |
| 빠른 입력 설정 | 채팅 입력칸을 눌렀을 때 접두사를 자동으로 넣거나, 채팅 옆 버튼에서 접두사를 잠시 끌 수 있습니다. |
| 채팅 통계 | 대화별 포인트 사용량, 활성 채팅 시간, 보낸 채팅 수를 기록하고 표시합니다. |
| 채팅방 바로가기 | 팝업에서 마지막으로 사용한 Eden Chat 대화방을 다시 엽니다. |
| 테마와 배치 | 확장 프로그램 및 프리셋 팝업의 테마와 채팅 옆 버튼 위치를 조정합니다. |

## 설치

### Chrome 또는 Edge에 개발자 모드로 설치

1. 저장소를 다운로드하거나 복제합니다.
2. `chrome://extensions` 또는 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 선택하고 이 저장소 폴더를 지정합니다.
5. `https://www.eden-chat.com/`을 새로고침합니다.

## 사용 방법

- 브라우저 툴바에서 **Eden Mate** 아이콘을 눌러 마지막 채팅방으로 이동하거나 빠른 설정을 조정합니다.
- **설정**에서 응답 알림, 테마, 채팅 버튼 위치, 통계 표시 및 수집을 변경합니다.
- **프리셋 편집**에서 문구와 단축키를 저장합니다. 채팅 화면 옆 접두사 버튼에서 목록을 열어 문구를 선택할 수 있습니다.
- 접두사 목록 맨 위의 **접두사 끄기**를 누르면 프리셋 입력이 비활성화됩니다. 목록에서 프리셋을 고르면 다시 활성화됩니다.
- 통계 창은 기본적으로 숨겨져 있습니다. 표시를 켜면 대화별로 기록된 항목을 볼 수 있고, 창을 드래그해 위치를 옮길 수 있습니다.

## 통계 계산 방식

- **포인트 사용량:** 응답 전후 화면에 표시된 잔액 차이를 기준으로 계산합니다. 잔액 표시나 응답 감지가 바뀌면 집계가 누락될 수 있습니다.
- **채팅 시간:** 해당 채팅 화면이 보이고 브라우저 창이 활성화된 동안 누적합니다.
- **보낸 채팅 수:** 화면의 사용자 메시지와 전송 동작을 함께 감지합니다. Eden Chat의 페이지 구조 변경에 따라 정확도가 달라질 수 있습니다.

통계는 대화 ID별로 저장됩니다. 화면 크기가 좁거나 입력창 주변에 배치 공간이 부족하면 통계 창 또는 프리셋 버튼이 숨겨질 수 있습니다. 자동 테마 감지는 Eden Chat의 화면 테마 표시를 기준으로 하며, 감지가 맞지 않으면 설정에서 다크/화이트를 직접 지정할 수 있습니다.

## 개인정보와 권한

Eden Mate는 별도의 계정이나 자체 서버를 사용하지 않습니다. 접두사, 설정, 통계 및 마지막 채팅방 정보는 Chrome/Edge의 확장 프로그램 로컬 저장소에 저장됩니다. 동기화나 외부 서버 전송은 하지 않습니다.

확장 프로그램은 동작을 위해 Eden Chat 페이지의 표시 내용을 읽습니다. 응답 완료 감지, 포인트 잔액 비교, 사용자 메시지 수 집계와 알림 미리보기에 필요한 범위입니다. 채팅 메시지를 확장 프로그램 외부로 전송하지 않습니다.

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 설정과 대화별 통계를 브라우저에 저장 |
| `notifications` | 응답 완료 데스크톱 알림 표시 |
| `offscreen` | Eden Chat이 백그라운드에 있을 때도 알림음 재생 |
| `https://www.eden-chat.com/*` | Eden Chat 화면에서 확장 기능 실행 |

자세한 내용은 [개인정보 안내](PRIVACY.md)를 확인하세요.

## 저장소 구조

```text
eden-mate/
├── background.js       # 알림과 백그라운드 오디오
├── content.js          # Eden Chat 기능, 프리셋, 통계
├── popup.html/js       # 툴바 팝업
├── options.html/js     # 설정 화면
├── offscreen.html/js   # 백그라운드 오디오 문서
├── ui.css              # 팝업 및 설정 스타일
├── fonts/              # 포함된 Pretendard 글꼴
├── sounds/             # 알림 샘플
└── manifest.json       # 확장 프로그램 설정
```

## 호환성과 참고 사항

- Chrome 및 Edge의 Manifest V3 확장 프로그램을 대상으로 합니다.
- 현재 `www.eden-chat.com`에서만 실행됩니다.
- Eden Chat이 채팅 화면 구조나 응답 상태 표시를 변경하면 관련 감지 로직을 조정해야 할 수 있습니다.
- 알림 표시 여부는 브라우저와 운영체제의 알림 권한 및 방해 금지 설정에도 영향을 받습니다.
- Pretendard 글꼴 라이선스는 [`LICENSE-Pretendard.txt`](LICENSE-Pretendard.txt)에 포함되어 있습니다. 프로젝트 소스 코드의 별도 라이선스는 아직 지정되지 않았습니다.
