채팅 버튼 위치

접두사 프리셋 버튼을 입력칸 옆에 표시합니다.

채팅창 기준 위치테두리로 표시된 채팅 입력 패널 바깥에 배치합니다.
✦

채팅 통계 창

창 표시와 통계 수집을 각각 설정합니다. 창은 기본으로 숨겨져 있습니다.

통계 창 표시채팅 화면 왼쪽의 요약 창을 표시합니다.
통계 수집창이 숨겨져 있어도 세 항목을 수집합니다. 포인트는 잔액 차이로 계산하며, 켠 뒤 완료된 응답부터 누적합니다.
포인트 사용량통계 창에 표시할 항목입니다.
채팅 시간통계 창에 표시할 항목입니다.
보낸 채팅 수통계 창에 표시할 항목입니다.
통계 창 위치드래그해 옮긴 창을 채팅 화면의 기본 위치로 되돌립니다.
